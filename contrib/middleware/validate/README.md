# Validator Middleware for Kratos Project

This module provides a middleware for Kratos to validate request parameters, using schema defined in `.proto` files.

There used to be a middleware named `Validator` in Kratos, which calls validation functions generated by
[PGV](https://github.com/bufbuild/protoc-gen-validate). PGV is archived and recommends
[Protovalidate](https://github.com/bufbuild/protovalidate) as its successor.

That's why we provide a new middleware that uses the schema definitions and validation functions provided by
protovalidate.

Protovalidate no longer requires validation code generation at build time. For compatibility with existing Kratos
projects, the middleware still invokes `Validate() error` when a request implements that legacy interface, without
depending on the archived PGV module or generator.
